# Knowledge OS

Personal knowledge management with Vue, NestJS and PostgreSQL / pgvector.

## Recovery status

The temporary development environment was reset. The previous local repository and its archives are unavailable in this environment. This repository is the persistent recovery location; this first commit records the state and working rules, not a completed application.

The original V1 specification remains the implementation target. Subsequent coherent changes will be committed and pushed here as requested by the owner. No online deployment has been completed yet.

## Working rules

Keep raw sources and provenance, version AI analysis, use modular source adapters, protect private data, and validate the critical ingestion/search flow before claiming the application is operational.
