Exporter vos publications depuis X Knowledge OS V12

1. Faites une copie de sauvegarde du dossier de votre extension actuelle.
2. Copiez les fichiers popup.html et popup.js de ce paquet dans CE MEME dossier, en remplaçant les deux fichiers existants. Ne modifiez pas manifest.json.
3. Ouvrez chrome://extensions, activez le mode développeur si nécessaire, puis cliquez sur Recharger sur votre extension V12 existante. Ne la supprimez pas et ne créez pas une nouvelle extension : son identité doit rester la même pour conserver son stockage.
4. Ouvrez la fenêtre de l’extension, puis Exporter vers Knowledge OS.
5. Dans Knowledge OS > Corpus X, importez le JSON obtenu.

Le bouton lit uniquement xHistoryPosts. Il n’exporte aucune clé OpenAI et n’envoie aucune donnée sur Internet. Le JSON contient vos captures privées : protégez-le.
Les réponses, projets et autres données V12 ne sont pas transférés dans ce premier import. Les textes générés par IA ne sont jamais pris pour des sources originales.
Seuls les contenus que vous pouvez consulter et conserver doivent être importés. Le bouton ne collecte aucun nouveau contenu et ne contourne aucune restriction X.
